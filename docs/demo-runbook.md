# MyVet — Runbook לדמו הסופי

עודכן: 17.07.2026

## 1. הכנה מקומית

דרישות: Node.js, npm וגישה לפרויקט Supabase דמו מאושר עם נתונים סינתטיים בלבד.

```powershell
npm ci
Copy-Item .env.example .env
npm run build
npm run test:vetbot
npm run dev
```

בקובץ `.env` המקומי מגדירים רק:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

אין להכניס לקובץ Vite את `GEMINI_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, סיסמת DB, Provider, Model, Prompt, role או Kill Switch.

## 2. הגדרות שרת לדמו הבטוח

כל יכולות שלבים 3–8 נשארות כבויות כמפורט ב־`demo-readiness-checklist.md`. `AI_ALLOW_MOCK_PROVIDER=false`. אין צורך ב־Edge Functions החדשות למסלול הליבה.

אם VetBot הקיים זמין בפרויקט הדמו, אפשר להציג אותו. אם הספק אינו זמין, מציגים את ה־fallback המקומי ואת הודעת הכשל המבוקרת; אין להפעיל Mock ב־Production ואין לזייף תשובה.

## 3. משתמשים

נדרשים שני חשבונות סינתטיים שנוצרו מראש ב־Supabase Auth:

- וטרינר דמו פעיל במרפאת הדמו.
- בעלים דמו המקושר רק לחיית הדמו.

שמות המשתמש והסיסמאות נשמרים במנהל סיסמאות/ערוץ פרטי ואינם נכתבים בריפו או במצגת.

## 4. מסלול יציב של 8–12 דקות

1. התחבר כווטרינר והצג שה־role נגזר מהשרת.
2. בדשבורד הצג את מרכז הפעולות, התור הבא ותורים שעברו.
3. פתח תור מהיום ועבור ישירות לתיק החיה.
4. הצג timeline רפואי, ביקור קיים, חיסונים ומסמך דרך Signed URL.
5. פתח יומן וזמינות: א׳–ה׳ 08:00–17:00, ו׳ 08:00–14:00, שבת סגור.
6. הצג שיחת DigitalCare, סטטוס אוטומטי, ארכיון וזרימת Google Meet. אין להפעיל תמלול AI.
7. הצג הזנה ידנית וסריקת ברקוד/מצלמה בפנקס החיסונים. OCR AI נשאר כבוי.
8. פתח VetBot ושאל שאלה תפעולית שאינה כוללת מידע אמיתי. אשר שהבוט אינו מבצע פעולה בלי preview ואישור.
9. התחבר כבעלים, הצג את החיה, התורים, ההתראות והמידע ששוחרר בלבד.
10. הוכח שטיוטות AI, תמלולים ו־Audit אינם מופיעים בפורטל.
11. הצג בוט קביעת תורים: פרטים חסרים, שעות פנויות ואישור לפני יצירה.
12. סכם את הפרדת ההרשאות והאישור האנושי.

## 5. מסלול AI מתקדם — רק לאחר Preview מאומת

לא מבצעים מסלול זה במצב הנוכחי. לאחר החלת Migrations, פריסת Functions ובדיקת ספק אמיתי ב־Preview ניתן להציג לפי הסדר:

1. טיוטת סיכום ביקור ואישור וטרינר.
2. טיוטת סיכום ללקוח, אישור ושחרור.
3. הצעת מעקב, עריכה ואישור תזכורת.
4. OCR למדבקת חיסון עם עריכה ואישור מפורש.
5. RAG רק לאחר אימות HNSW, הרשאות וכיול.

## 6. תוכנית גיבוי

- VetBot לא זמין: הצג fallback מקומי וזרימות ידניות.
- Meet לא זמין: הצג קישור והיסטוריית session בלי לפתוח שיחה.
- Supabase לא זמין: השתמש בצילומי מסך/וידאו שהוכנו מראש מנתונים סינתטיים; אל תמציא פעולת DB.
- Build מקוון לא זמין: הרץ את ה־Build המקומי שכבר עבר.
- אין הרשאה ליכולת AI: הסבר שה־Feature Flag כבוי מטעמי בטיחות והמשך בליבה.

## 7. סיום הדמו

- MyVet מרכזת עבודה קלינית, תפעולית ופורטל בעלים באותה מערכת.
- RLS, פונקציות שרת ואישור אנושי מגנים על מידע ופעולות.
- VetBot מסייע; הוא אינו מחליף וטרינר ואינו משנה טיפול או רשומה בעצמו.
