# VetBot — אימות מלא של פעולות וניסוח עברי טבעי

עודכן: 19.07.2026  
ענף עבודה: `Full_Demo`

## שורש התקלה

- פעולות השרת והאישור האנושי היו תקינות, אך התאמת שמות מטופלים ופריטי מלאי דרשה התאמה כמעט מדויקת.
- בקשות מלאי ברורות בעברית, כגון “הוסף יחידה”, לא תמיד מילאו את `inventoryOperation`, ולכן VetBot נתקע בשאלת המשך.
- קטלוג הפעולות תמך בעדכון כמות של פריט קיים בלבד ולא ביצירת פריט חדש.

## מה תוקן

- נוספה השלמה דטרמיניסטית של `add`, `remove` ו־`set` מתוך ניסוח עברי ברור.
- נוספה התאמת שם מנורמלת עם סבילות לניקוד, סימני פיסוק וטעות כתיב קטנה, אך רק כאשר מתקבלת התאמה יחידה. התאמה עמומה עדיין דורשת הבהרה.
- נוספה הפעולה `create_inventory_item` עם Preview ואישור מפורש.
- יצירת פריט מאמתת שם, קטגוריה, כמות, סף ומחיר ומונעת שם כפול.
- נוספה פונקציית Supabase מוגבלת למשתמש מחובר ובעל תפקיד צוות פעיל; `anon` אינו מורשה להפעיל אותה.
- עודכנו Prompt ו־Output Schema לגרסה `2026-07-19.2`.
- נוספה הבנת כוונה בעברית טבעית גם ללא מילת פקודה מדויקת, למשל: “תשריין”, “תאם”, “הזז”, “שים בצד”, “לא סובל דיחוי”, “קיבלנו”, “השתמשנו” ו־“קח אותי”.
- נוספו חילוץ תאריך ושעה מניסוחים כמו “מחר”, “מחרתיים”, “בשמונה בבוקר” ושעות מפורשות, וכן זיהוי סוג תור, מספרי תורים/שיחות/בדיקות וטווחי חסימת יומן.
- נוסף מסלול התאוששות מקומי ומוגבל לפעולות עסקיות כאשר ספק ה־AI אינו זמין. המסלול רק מכין Preview מאומת; הוא לעולם אינו מבצע פעולה בלי אישור המשתמש.
- נוספו מסלולי התאוששות בטוחים גם לניווט, טיוטות וחסימת פעולות אסורות. טיוטה אינה נשלחת אוטומטית ופעולה אסורה אינה מתבצעת.
- ברירת המחדל של המודל הועברה ל־`gemini-2.5-flash-lite`, ולאחריו `gemini-2.5-flash` ו־`gemini-3.5-flash` כחלופות.

## אימות שבוצע

- עדכון נורופן מ־1 ל־2 דרך VetBot ואישור בפועל; לאחר מכן הוחזר ל־1.
- יצירת “פריט בדיקת VetBot” דרך VetBot ואישור בפועל; לאחר מכן הפריט נמחק.
- “באל” זוהה כ־“בל” רק כהתאמה יחידה, תור נוצר בפועל ולאחר מכן בוטל.
- `npm run typecheck:ai`, `npm run test:vetbot`, `npm run build`, בדיקת סודות ו־`git diff --check` עברו.
