CODEX AUTO RESUME - SUPER v5
============================

מה החבילה עושה
---------------
1. שומרת וממשיכה את אותו Codex Thread ID.
2. אם מגבלת 5 השעות נגמרת בוודאות - ממתינה לאיפוס וממשיכה את אותו Thread.
3. אם המכסה השבועית נגמרת - עוצרת לחלוטין.
4. אם זו מגבלת קרדיטים/חשבון/מגבלה נוספת - עוצרת ולא מנחשת.
5. אם אי אפשר לקבוע בוודאות איזו מכסה נגמרה - עוצרת בבטחה במקום להיכנס ללולאה.
6. מונעת מהמחשב להיכנס ל-Sleep בזמן שהמפקח פעיל, בלי לשנות את Power Plan של Windows.
7. שומרת state.json + גיבוי + לוגים + Thread ID.
8. מציגה דף סטטוס בעברית UTF-8, RTL אמיתי, דרך הדפדפן.
9. מונעת שני מופעי Supervisor במקביל.
10. אם Codex מחזיר Thread ID אחר בזמן Resume - עוצרת מיד ולא עוברת לשיחה אחרת.
11. מאפשרת עצירה בטוחה דרך Stop-Codex-Auto-Resume.bat או Ctrl+C.
12. עושה Retry מוגבל רק לתקלות רשת/שירות זמניות; לא עושה Retry עיוור לשגיאות אחרות.

שמירת המצב מהגרסאות הקודמות
----------------------------
אל תמחק את התיקייה .codex-auto-resume שכבר קיימת בפרויקט.
הגרסה הזו קוראת את state.json הישן של V1-V4, שומרת את threadId וממירה את המצב לפורמט החדש.
כלומר: החלפת קבצי הסקריפט אינה מוחקת את ה-Thread שכבר שמרנו.

התקנה / שדרוג
-------------
1. סגור Codex App, Codex ב-VS Code וכל חלון Codex אחר שמשתמש באותו Thread.
2. אל תמחק את .codex-auto-resume מהפרויקט.
3. העתק לתיקיית הפרויקט את חמשת הקבצים:
   codex-supervisor.js
   Start-Codex-Auto-Resume.bat
   Stop-Codex-Auto-Resume.bat
   Open-Codex-Status.bat
   Check-Codex-Auto-Resume.bat
   (Self-Test.bat אופציונלי)
4. אפשר למחוק/להשאיר את codex-auto-resume.ps1 הישן; הגרסה החדשה לא משתמשת בו.

לפני הלילה הראשון - מומלץ מאוד
-------------------------------
לחץ פעמיים על Check-Codex-Auto-Resume.bat.
הבדיקה אינה שולחת משימת עבודה ואינה משנה קוד בפרויקט.
היא בודקת Node, Codex CLI, קריאת מכסות, מניעת Sleep, הרשאות כתיבה וה-state השמור.
ייפתח דוח בעברית בדפדפן.

הפעלה
-----
לחץ פעמיים על Start-Codex-Auto-Resume.bat.
ייפתח דף status.html בדפדפן. זה הדף שאמור לשמש אותך במקום לקרוא טקסט עברי ב-CMD.

עצירה בטוחה
-----------
לחץ פעמיים על Stop-Codex-Auto-Resume.bat.
בזמן המתנה האוטומציה תפסיק כמעט מיד.
בזמן ש-Codex עובד, המפקח נותן ל-Turn הנוכחי להסתיים ואז עוצר לפני שליחת בקשה נוספת. זו העצירה הבטוחה ביותר כדי לא לקטוע כתיבה לקבצים.
Ctrl+C מבקש גם הוא עצירה; הדרך המומלצת היא Stop-Codex-Auto-Resume.bat.

חשוב
----
- אל תפעיל במקביל Codex App/VS Code Codex על אותו Thread.
- אל תסגור את מכסה הלפטופ אם אצלך סגירת המכסה מכניסה את Windows לשינה.
- המסך עצמו יכול להיכבות; מניעת השינה מתייחסת למחשב.
- אין כאן עקיפה של מכסות. המפקח רק ממתין לאיפוס שהשירות מדווח עליו וממשיך לאחר מכן.
- אף תוכנה אינה יכולה להבטיח "אפס באגים" בכל גרסה עתידית של Codex. לכן החבילה כוללת Doctor, Self-Test והתנהגות fail-closed: במקרה של חוסר ודאות היא עוצרת במקום לנחש.
